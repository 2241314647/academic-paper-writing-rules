# 科研论文框架与语言规范｜Academic Paper Writing Rules

这是一套可复用的论文写作与修改规则，面向 EEG／脑机接口、医学数据分析及其他实证研究。它要解决三个反复出现的问题：**各章节写不到点上、正文像在翻译表格、AI 语言过度包装且处处自我辩解。**

核心原则：**创新说清，证据说准，语言说实，篇幅做减法。**

## 文件说明

| 文件 | 用途 |
| --- | --- |
| [MASTER_PROMPT.md](MASTER_PROMPT.md) | 唯一的完整主提示词。新建论文或改稿时直接复制给 AI。 |
| [ARTICLE_BRIEF_TEMPLATE.md](ARTICLE_BRIEF_TEMPLATE.md) | 每篇论文的输入信息表，避免把某一篇文章的实验设置套用到下一篇。 |
| [AGENTS.md](AGENTS.md) | 让 Codex 等代码代理在此仓库工作时自动遵循主提示词。 |

## 使用方法

1. 打开 **MASTER_PROMPT.md**，复制全文到新的 AI 对话／Codex 任务。
2. 按 **ARTICLE_BRIEF_TEMPLATE.md** 填写论文的问题、贡献、真实结果、目标期刊/会议、写作或改稿范围。
3. 上传当前论文、图表和参考文献；如需修改，指定“只改摘要／引言／方法 D／结果”等确切范围。
4. 要求返回完整可替换的文本或 Overleaf 源码，并对照主提示词执行最终检查。

## 适用边界

- 这是**写作规则**，不是某个模型、数据集或实验的预设结论。
- 会议页数、引用上限、图注格式、文稿语言等，以**当前目标刊会**的要求为准；例如 EMBC 项目可设置参考文献不超过 20 项，但其他论文不要机械沿用。
- 论文必须尊重实际数据。**拒绝防御性废话，不等于隐藏不显著、相反或不支持结论的结果。**准确性通过结论措辞和必要的集中讨论体现，不在每个句末追加免责条款。
- 此仓库不存放尚未公开的论文正文、患者数据、账号信息或作者个人资料。

## 一句话验收

读者能迅速回答：**研究问题是什么 → 实际新方法是什么 → 如何公平验证 → 实验发现了什么 → 这些发现为什么重要。**
