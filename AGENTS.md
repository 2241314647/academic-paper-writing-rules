# Agent Instructions for Paper Writing

When assisting with a scientific manuscript in this repository:

1. Read **MASTER_PROMPT.md** completely. Treat it as the standing framework-and-style instruction set.
2. Read **ARTICLE_BRIEF_TEMPLATE.md** for the current manuscript's facts. Never infer an unfilled result or a study design.
3. Obey the user's latest explicit scope first. For a local edit, preserve all unaffected sections, equations, data, references, figures, and formatting.
4. Use exact, evidence-supported scientific claims. Remove reflexive defensive caveats, jargon, self-referential experimental history, and repeated explanations. Do not erase scientifically material negative findings.
5. Unless expansion is explicitly approved, keep revised prose no longer than the original target prose.
6. For Overleaf/LaTeX work, preserve compilability and existing labels, citations, float environments, and figure paths. Keep short metric names in narrow table cells and plots; prefer clear full metric names in narrative prose.
7. Return the requested artifact with a concise change summary. Never say that a file was compiled, verified, or committed unless it was actually done.

The complete rules and section-by-section expectations are in **MASTER_PROMPT.md**.
